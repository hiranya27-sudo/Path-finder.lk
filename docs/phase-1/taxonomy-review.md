# Phase 1 — Draft Taxonomy Review

The development roadmap calls for a canonical catalog of 44 technical skills
across 19 IT roles, excludes soft skills, and does not provide the catalog
itself. The accompanying seed file supplies an initial draft so the schema
and data flow can be exercised; it is not evidence of local employer demand
and should not be described as a validated research result.

## Before approving this catalog

1. Ask the supervisor to confirm the intended role definitions and scope.
2. Have Sri Lankan IT practitioners and/or lecturers review role titles,
   canonical technical skills, aliases, and required levels.
3. Compare the draft with a permissioned, dated sample of local job adverts.
4. Record disagreements and decisions, including the version and reviewers.
5. Confirm that no soft skill is being used as a model feature.
6. Re-check the approved baseline count: exactly 44 canonical skills across
   exactly 19 roles, each skill and role linked to at least one requirement.
7. Treat `importance_weight` and each required proficiency level as expert
   judgments until they have an agreed calibration procedure.

## Seed contents

The seed contains programming, web/backend development, mobile development,
databases, data/analytics, cloud/DevOps, machine learning, cybersecurity,
networking, quality engineering, and UI/UX technical skills. Each role-skill
mapping is an editable hypothesis, not a claim that every employer requires
the listed stack.

## Reproducibility

Store future accepted changes as a new reviewed migration/seed version rather
than silently changing a taxonomy used to generate research results. Preserve
the taxonomy version with recommendations and evaluation snapshots.
